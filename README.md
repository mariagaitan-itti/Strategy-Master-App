# Strategy Master App

Dashboard estratégico SuperApp — Grupo Vázquez / ueno (2026).

## Preview local
```bash
python3 -m http.server 8080
# abrir http://127.0.0.1:8080
```

## Deploy (Apps Script)
Copiar y pegar el contenido de `index.html` en el archivo HTML `Index` del proyecto Apps Script y publicar una nueva versión.
Guía completa y checklist en [`docs/DEPLOY_APPS_SCRIPT.md`](docs/DEPLOY_APPS_SCRIPT.md).
